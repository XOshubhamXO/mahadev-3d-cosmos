### 3. 🎯 Multi-Axial 6-DOF 3D Navigation & Focal Zooming

## 🚀 Getting Started

### Prerequisites
- Node.js 20+ LTS
- pnpm / npm

### Installation & Local Preview

```bash
# Clone the repository
git clone https://github.com/XOshubhamXO/mahadev-3d-cosmos.git
cd mahadev-3d-cosmos

# Install dependencies
pnpm install

# Start local development server
pnpm dev
# ➜ Local: http://localhost:5173

# Build for production
pnpm build

# Preview production build
pnpm preview
```
